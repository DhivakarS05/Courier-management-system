Courier Management System

A web-based **Courier Management System** developed using **Python Flask and MySQL**. The project helps manage courier bookings, customers, staff assignments, delivery status, and courier tracking.

Features

* Admin, Staff, and Customer modules
* Customer registration and login
* Courier booking
* Courier tracking
* Staff assignment
* Delivery status management
* Customer and courier management
* MySQL database integration

Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

Project Objective

The main objective of this project is to digitize courier operations and provide an easy way to manage courier bookings, deliveries, staff, and customer information.
